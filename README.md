# 우리의 모든 순간 · 졸업영화 편집실

학년별 사진과 편지, 음악으로 성장 영화를 만드는 태블릿용 웹 편집기입니다. 학생이 선택한 자료는 브라우저 안에서 처리합니다. 작업 백업에는 개인 사진이 포함되므로 기기에 보관하세요.

## GitHub Pages 발행

공개 저장소의 main 브랜치에 docs와 tests 폴더 및 README.md를 올리세요. Settings → Pages → Deploy from a branch에서 main과 /docs를 선택한 후 Save를 누르세요. 배포가 끝나면 Visit site로 접속할 수 있습니다.

## 확인

프로젝트 폴더에서 `node --test tests/*.cjs`로 테스트를 실행하세요. 글꼴의 라이선스 원문은 docs/fonts에 있습니다.
